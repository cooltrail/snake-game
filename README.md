# Snake

A classic Snake game you can play right in your browser. No build step, no dependencies — just HTML, CSS, and vanilla JavaScript.

## Play

Live at: https://cooltrail.github.io/snake-game/

## Controls

- Arrow keys or WASD to move
- Space to pause/resume
- On mobile: swipe on the board, or use the on-screen D-pad
- Best score is saved locally in your browser

## Run locally

```bash
cd snake-game
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Deploy

This is a static site with no build step, served via GitHub Pages directly from the `main` branch root.
